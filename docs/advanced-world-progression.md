Optional bonus levels remain outside this PR.

PR34's existing progress retention protects already-earned cosmetic rewards. Exact transcendental coordinate notes belong to the level data and appear in all modes, including Ace; no rounded substitute is required. The new gate geometries are authored independently of student equations. Optional gems remain optional.

Verification: every reference route visits all its intended cannons, clears terrain continuously, banks every authored gem and supports the existing creature/animation/mode state machine. Reference equations stay in tests. All nonadjacent forward shortcuts in the advanced relays are audited using conservative forced-turn constraints from the actual gate intervals, with wave cannons terminal to avoid unrestricted periodic shortcuts. The proof concerns forward skips, not arbitrary alternative valid routes. Browser journeys cover all seven function families across the final relays, and the full-catalogue regression covers all 216 level/mode combinations.
