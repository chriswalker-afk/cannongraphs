# PR20 — World 6: Beyond the Graphiverse

Twelve levels replace the final engine preview. The catalog contains six complete worlds and 72 unlocked levels. Each new puzzle includes optional gems; existing creature budgets, launch rules, feedback and star scoring are unchanged.

| Level | Focus |
| --- | --- |
| 1 Starburst | Exponential growth |
| 2 Fading signal | Exponential decay |
| 3 Natural reversal | Reflection and translation of natural exponential |
| 4 Log beacon | Base-10 logarithm, powers of ten |
| 5 Natural orbit | Natural logarithm and translation |
| 6 Reflected horizon | Reflected log domain, reverse flight |
| 7 Sine signal | Sine amplitude and period (radians) |
| 8 Cosmic tide | Cosine, full period |
| 9 Phase shift | Translated/reflected sine, leftward flight |
| 10 Tangent tunnel | One connected tangent branch |
| 11 Deep-space relay | Exponential, logarithmic and periodic wave |
| 12 The Graphiverse gauntlet | All seven families in one seven-leg route |

Natural reversal and Natural orbit use exact irrational x-coordinates, identified in the objectives; inspection displays the usual rounded numerical values. Students should use the exact expressions when constructing their equations. Some optional gem coordinates approximate logarithmic values within pickup tolerance. The supported expression grammar and floating-point tolerances are unchanged from PR18. Reference equations live only in the test suite.

In the last two levels, full-height solid gate pairs constrain nonadjacent shortcuts. Tests derive vertical free intervals from actual terrain at ordered x-slices. A sequence of alternating strict rises and falls gives a lower bound on the number of turning points of a differentiable function. This excludes exact-anchor shortcuts by linear, quadratic, cubic and connected reciprocal/exponential/logarithmic branches (the wave cannon is last). Endpoint intervals allow capture tolerances. The actual reference routes are also checked with continuous collision and clearance audits, and all gems must be collected along those routes. Separate tests exercise reverse flight, tangent branch failure, equivalent functions and seven-leg rapid-fire.

The cosmic theme uses pale nebula colours, planets, constellations and spacecraft silhouettes behind a legible coordinate grid. Station terrain uses clipped alloy panels. All decorations are non-colliding; solid rectangles remain the authoritative geometry. The final puzzle has an extra completion message, not a claim that a player has completed every preceding level, because all levels are unlocked.

Manual browser QA remains outstanding, especially on narrow screens with seven cannon cards, the wide finale at default zoom, exact-coordinate objective readability and reduced-motion celebrations. Progress persistence and final menus remain Phase 4 work. Next PR21: animated home screen.
