# PR6 — Core gameplay loop and misfires

The level state is a pure immutable reducer-style module. A valid launch reserves one Pip immediately. The active attempt holds a deterministic result and monotonic ID; completion can only resolve that exact attempt once. Queue invariant: waiting + active + failed + saved = total. Invalid/empty/nonlinear input never starts an attempt. Failed launches (obstacle, boundary, misfire) consume exactly one creature, keep the equation and outcome trail, and unlock editing if any remain. The fifth failure ends the level. A successful attempt ends the challenge immediately, with one arrived and the remaining Pips waiting for PR7's automatic rapid-fire sequence. No premature credit or stars. The queue reflects the actual budget and outcomes.

Restart is disabled during animation. Restart clears equations, results and the queue; retrying after game over or replaying after success refills the queue but retains the last entered equation. Editing during a retry clears the old trace and returns the cannon to its default orientation; it never restores a used creature. Terminal cards are keyboard focusable and explain the next action. No backend or persistent progress yet.

## Misfire
A valid linear equation that misses the source is a failed attempt, not a syntax error and not a collision. The cannon uses its neutral barrel angle, with no muzzle flash or recoil. The Pip limply tumbles out from the marked muzzle, rolls down to a nearby ground position, pauses with drooping arms, downturned mouth and disappointed eyes, then slowly walks off, with alternating foot motion and a fade. No dashed path or imaginary flight is drawn. The original source mismatch is retained in the mathematical result and feedback. The animation is local staging only, not a second mathematical flight: it chooses a nearby support surface and restricts the departure on that support; for future complex floating/obstructed cannon locations this visual gag may require authored staging. Reduced motion replaces the tumble and walk with brief stationary disappointed poses. No splat or dizzy stars are used.
