# PR21 — Animated home screen

Cannon Graphs now opens on a lightweight, responsive landing screen with a prominent title, a short invitation, live original vector artwork and one primary Play action. The landscape scene uses the game's real linear, quadratic, cubic and wave flight engine; narrow/portrait screens use a compact three-cannon switchback so the sprites remain readable. These authored demonstration routes are separate from the 72 playable levels. No actual level answers are exposed. Mathematical traces, cannon angles, cheerful Pips, smoke/recoil and the portal celebration reuse the production animation/rendering code. The waiting Pips bob gently and a small batch flies repeatedly, with a rest between cycles. Scenic hills, clouds, a distant castle and waterfalls are non-colliding art.

The demo is decorative (hidden from assistive technology); meaningful controls remain native HTML. Pause animation is available, and a hidden tab stops the frame scheduler. As of PR30, the demo animates by default on every device unless the player has explicitly chosen reduced motion in this page session. Leaving the home page cancels the animation and removes visibility and resize listeners. It does not start an attempt, use a creature, award a gem/star or modify any progress. Play opens the first level on a fresh page load, or the last selected level on a return to the home screen within the same page session; it starts a fresh run rather than storing drafts. The home icon in the game header returns to the landing screen outside an active launch/celebration. The existing grouped level selector remains available; the dedicated world/level selection screen belongs to PR22.

Regression tests cover both demonstration layouts and their continuous route clearance, route-family animation/timing, static compositions, responsive layout choice, loop boundaries and scheduler lifecycle. No browser-level visual or device QA has yet been performed; verify portrait phones, classroom landscape, short desktop windows, keyboard navigation, visible pause/play control, reduced motion, and switching between home and a playable level. Next PR22: distinct world and level selection, with all levels still unlocked.
