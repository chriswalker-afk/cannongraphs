# PR32 — Cannon programming pop-up and status halos

Click, tap or keyboard-activate a cannon to open a nonmodal editor beside it. Previous/Next navigate the authored cannon order, disabled at the ends. Done/Escape close the pop-up and return focus. The compact footer retains readiness, status legend, launch/restart and actual attempt feedback, not a persistent equation panel or equation-card rail. On narrow/short screens the editor is clamped to the visible stage/viewport and scrolls internally; zoom, resize and navigation reposition it. If the next cannon is offscreen, reset the camera to show the full level. The pop-up closes during flight.

Every cannon defaults to editable parameter boxes (including Ace). Linear uses y = [m] x + [c]. Enter signed rational values exactly; blank boxes are not zero. ArrowUp/Down and adjacent buttons step by 1 (Shift+arrow by 1/10), retaining exact fractions. Advanced fields can include pi/e. Quadratic expanded, turning-point and factorised forms; cubic expanded/shifted; reciprocal; exponential base/natural; log/ln and sin/cos/tan are available. Free equation mode retains the existing parser, tools and all equivalent forms. Returning from an expanded polynomial free equation converts exact coefficients; a nonconvertible free expression requires confirmation before starting blank boxes. Changing form starts a new equation. Drafts including partial/invalid fields and chosen forms survive switching cannons; replay retains equations, restart clears them. Cadet-only guidance/preview and Ace restrictions on hints/coordinates/preview remain; boxes are now common input controls.

Orange halo: unprogrammed or incomplete/invalid. Light green: valid equation, not yet flight-tested. Red: the last actual attempt ended at this cannon (including misfires, splats, domain/boundary/loop failure). Dark green: actual unchanged equation successfully reached another cannon or exit. Evidence is recorded after the attempt resolves, not guessed from the equation. Editing clears only that cannon's evidence; unvisited cannons retain their status. Halo color is complemented by accessible status labels and a legend. No changes to mathematics, source checks, collision or scoring. Reference solutions stay test-only.

New unit and Chromium tests exercise exact coefficients, forms, invalid boxes, draft navigation, viewport bounds, all halo transitions and advanced free-equation fallback. Existing browser journeys migrate to the pop-up. Real-device visual review remains outstanding.
