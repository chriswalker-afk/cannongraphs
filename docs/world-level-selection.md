# PR22 — World and level selection

Play now leads to an illustrated destination menu rather than starting the first level automatically. Choose one of six worlds, each with its own landscape art, colour palette, mathematical focus and curriculum summary. Original static SVG postcards reuse scenery, Pip and cannon artwork. The art is decorative and does not depict solutions.

Inside a world the twelve numbered buttons are compact and colour-coded by world. All 72 levels are unlocked; there is no fabricated difficulty score, star rating or progress lock. Selecting a number reveals that puzzle's title, objective, actual cannon families/counts, Pip budget and optional gem count. Play level is a separate explicit action. New worlds start with no selected level, except the last played level is highlighted when revisiting its world during the current page session. The world selection state has no attempt or progression data, and is independent of the engine.

Back to worlds and Home navigation use native buttons. The in-game header's compact Levels button opens the current world's menu with the current level selected. Like the previous navigation, leaving a run discards its equations and attempts; navigation is disabled during active flight or rapid-fire. Next level/world after a success continues directly as before. Selecting a level starts a fresh run. Home animation is cleaned up before entering selection; selecting a world starts no animation or attempt. The latest selection is retained only as the last actually played level in this page session.

Responsive layout uses desktop three-by-two destination cards, a two-column portrait grid, and compact numbered level buttons with one detail panel. On very short/narrow displays the menu can scroll rather than clip controls. Native controls have accessible names, selected level uses aria-pressed, screen headings receive keyboard focus on navigation, and Back restores focus to the corresponding world card. No preview graphs, answers, locks or progress persistence are introduced. The pure selection state allows PR23 to insert a learning-mode choice and PR24 to attach real completion data without changing puzzle definitions.

Seven new unit tests cover every level's reachability, invalid/cross-world navigation, return and back behaviour, identity metadata and derived puzzle details. Browser QA still outstanding: world/level layout and focus on desktop, mobile portrait and short landscape, level selection details for seven families, return from game and home, and existing progression.
