# PR39 — Level Workshop

Open **Level Workshop** from the home screen. Drag a palette tool onto the coordinate grid, or select it and click/tap the grid. All seven graph families, the exit, platforms, walls, ceilings and optional gems are available. Select/move objects by dragging or use the inspector for exact x and y coordinates, cannon family, left/right direction, starting cannon and terrain width/height. Select terrain then drag a rectangle to draw its actual collision geometry; dropping a palette terrain tool creates a default-sized rectangle. Grid limits and theme can be changed; the base floor is automatically included. Snap to whole, half or quarter units. Keyboard users can select a tool, focus the board, move its cursor with arrow keys, press Enter to place and use the object list/inspector for precise editing.

## Design → Playtest → Confirm → Share

- The current design is an autosaved local draft, with a clear session-only status if storage fails. New/upload replaces the current draft with confirmation. Download a confirmed design before replacing it.
- The playtest button is available only after the design passes structural validation, including finite bounded coordinates, supported cannon/exit anchors, clear start and destination points and enough space for waiting Pips.
- Playtest opens the real game with unlimited Cadet attempts. The equations are entered through the real cannon pop-up. It uses the actual parser, route simulation, collisions, animation, and completion state. Completing the celebration and saving all practice Pips marks the exact design as tested. Bypassed cannon routes are flagged for review but follow the regular game's win condition; optional gems need not all be collected. Neither previews nor failed or unfinished flights count.
- Return to the workshop and explicitly confirm. Download is enabled only after confirmation. Changing a design (including name, instructions or theme) invalidates its test/confirmation, even if manually reverted later.
- Download saves a versioned `.cannon.json` file containing geometry and metadata, never the author's flight equations or local proof. Upload accepts bounded, structurally playable files; unrecognised properties are discarded. Imported designs open as playable drafts, not locally confirmed levels. To re-export them, complete a local playtest and confirm.
- This is browser-local, not a trusted or tamper-proof publication system. There are no accounts, server storage or public user-generated level listings. A user's local storage can be altered by that user. Share files through the school's normal channels. The regular catalogue, records and cosmetic rewards are unaffected.

Limits: grid coordinates within ±100, integer bounds, 6–40 units wide and 5–24 units high, eight cannons, 40 terrain pieces plus the base floor and 24 gems, 64 KB upload. Terrain uses the exact rectangles shown in the workshop; the game renders the themed scenery and computed visual supports. Placement near edges/inside terrain may be temporarily invalid while editing; the test button explains blockers. Real-device review remains necessary.

Regression tests cover all seven families, bounded decoding, geometry, successful and failed flight, stale test proof, confirmation invalidation, download/import, storage errors, separate progress and mouse/keyboard/mobile interactions.
