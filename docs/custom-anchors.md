# PR55 — Anchor-placement authoring

Enable **Anchor placement puzzle** in the workshop's Build palette. This selects the Salvage Yard visual theme. The original fixed-cannon and vertical-lift authoring controls remain available when anchor mode is off. Rail and anchor mechanics are separate; remove rails before enabling anchor mode, and remove mounts/parts explicitly before leaving it.

Place fixed cannons, exit, terrain and gems as before. The Candidate mount tool uses drag/drop, tap placement, keyboard grid placement, exact-coordinate properties and object deletion. Add linear or quadratic inventory parts with separate tray buttons; they have no authored muzzle position. Choose family and direction, optionally lock the nonconstant coefficients, and apply the zero-constant expression. Unlock before changing the family. Up to twelve mounts, four inventory parts and eight total cannons; a fixed starting cannon is required. Drafts may be incomplete. Playtest is enabled only for structurally valid geometry, adequate supports, sufficient candidate mounts and waiting-Pip space. There is no hidden correct-mount flag and no automatic uniqueness restriction on custom levels.

Playtest uses the actual Salvage Yard tray and simulator. All parts must be mounted, programmed and used in the relay. Completion validates the selected revision, canonical authored geometry, allowed mount assignments and the actual reached anchors. Locked anchor legs are independently re-simulated to reject an incorrect arc with matching endpoints. Editing any anchor, part, shape or other authored property invalidates the local confirmation and records. Replay retains placement during a run; workshop, restart and exports retain the original empty inventory.

Version 3 share files contain only the normalized authored design, including empty candidate mounts and part family/direction/locked shape. Runtime positions, equations, confirmation, records and solution assignments are not exported/imported. v1 ordinary and v2 Foundry/lift files retain their formats and design fingerprints. The existing local library storage remains compatible; anchor drafts and confirmed levels show mount/part counts, empty-mount thumbnails and searchable family/theme text. Imported designs require a fresh local playtest to confirm.

Tests cover both design modes, ID and capacity constraints, invalid shape/geometry, sharing normalization, exact locked-path proof, revision-bound local confirmation, custom-mode records, and actual workshop/playtest/download/upload journeys on desktop and mobile. PR55 also updates the inherited Foundry touchscreen regression to use the same native CDP gesture timing as the passing Salvage Yard test. Physical touchscreen verification remains outstanding.

PR56: promote the twelve Salvage Yard puzzles into the official eighth world, 96-level curriculum, standard category/mode selector, records, artwork/music and achievements. Audit difficulty and accessibility, then review the deployed game.
