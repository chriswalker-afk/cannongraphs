# Cannon Graphs!

A graph-sketching adventure: program equations to launch Pips through seven worlds and 84 puzzles. Seven function families, three learning modes, optional gems, local progress, unlockable cosmetics and optional original audio.

- [Play](https://chriswalker-afk.github.io/cannongraphs/)
- [Classroom guide and QA](docs/classroom-qa.md)
- [Difficulty progression and audit](docs/difficulty-audit.md)
- [Design](docs/design.md) · [Roadmap](docs/roadmap.md) · [Development](docs/development.md)

Each world has three one-cannon, three two-cannon, three three-cannon and three four-cannon levels, grouped as Introduction, Development, Challenge and Mastery. All levels are available from the start. Audio is muted by default. No accounts or network services are required to play; progress and settings stay on the browser.

New to Cannon Graphs? Flight School opens before Meadow Launchers level 1, with an unscored worked coordinate-to-equation example, a practice relay and a real splat/retry. Reopen it from the first level toolbar. [Tutorial design](docs/first-flight-tutorial.md).

The Level Workshop lets you drag graph cannons, an exit, terrain and gems onto a coordinate grid, test the design in the actual game, then confirm and download the level file. Upload a shared JSON level to playtest or edit it. Custom progress is separate from the 84-level curriculum. [Workshop guide](docs/custom-level-workshop.md).

Custom Levels is a local library for up to 100 saved designs. Create or import multiple levels without replacing earlier work; search, filter, edit, duplicate, delete and play in Cadet, Pilot or Ace mode. Each level has separate play records and designer confirmation. See [Custom Level Library](docs/custom-level-library.md).

**Broken Foundry (World 7):** twelve official levels introduce vertical translations of locked linear and quadratic graphs using movable cannon platforms. Progress is saved in the existing Flight Log; lift flight tests remain separate practice. Custom workshop levels can use movable cannons and the Foundry theme. See [Foundry integration](docs/foundry-integration.md).
